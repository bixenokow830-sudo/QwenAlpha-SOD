# QwenAlpha-SOD 全监督路线详细计划书

版本 v1.1 · 2026-11-11 · Harness / Codex 共用

## 1. 路线目标与当前进展

在 EORSSD、ORSI-4199 和 ORSSD 上，用训练集完整像素 GT 训练遥感显著性检测器，检验冻结 Qwen-Image-2.1 生成的显著性先验在全监督条件下能否提升预测质量。首版以冻结 DINOv2 编码器和轻量解码器为基础，训练显著图预测头。该选择可复用已有训练链路，并通过配对实验单独检验 Qwen 输入的贡献。

本计划作为新增路线独立立项，编写时点的共享进度为 v9.45。原弱监督 R7 缓存停在 538/2999，R8 加速筛选为 no-go，Qwen 本体 LoRA 已测试配置在 Q3 收尾。全监督路线以 FS0–FS7 编号，本文交付时各步骤均待执行。

| 已验收资产 | 结果与用途 |
|---|---|
| W5 B500 全监督参照 | 500 张训练图、350 输入、冻结 DINOv2 与轻量解码器、BCE + soft Dice。dev100 最佳 step 2250，Sα 0.866471、MAE 0.014728。作为实现和量级参照，复用既有验收。 |
| W5 B500 全监督官方测试 | 2,999 张官方测试图合并 Sα 0.750656，弱监督 seed0 为 0.723305。两者是单种子事后对照，且训练损失有差异。 |
| R6/R7/R8 既有缓存 | 候选复用资产。按样本内容、冻结推理参数及产物哈希逐条确认，使用范围由本路线的数据角色决定。R8 的 4 步平均耗时 32.72 秒，低于 15 秒的筛选门槛未通过。 |

依据：[共享进度说明书](QwenAlpha-SOD_Harness与Codex共用进度说明书.md)、[B500 全监督开发集参照](QwenAlpha-SOD_B500全监督开发集参照_2026-11-07.md)、[B500 全监督事后官方测试](QwenAlpha-SOD_B500全监督事后官方测试_2026-11-07.md)、[弱监督修正实验计划](QwenAlpha-SOD_Qwen弱监督修正实验与Harness共用计划书.md)。

## 2. 数据划分与 GT 访问

- **训练候选池。** 三套原训练清单当前共 4,000 条记录，EORSSD 1,400、ORSI-4199 2,000、ORSSD 600。实际可训练规模由 FS0 在完成图像与 GT 对应检查、跨角色排重后确定。B500 档从原 B500 的合格样本继承，按预冻结规则从训练池同源补足，记录每项替换。后续可用 B500 ⊂ B1000 ⊆ 全部合格池的嵌套清单比较标注预算。
- **开发与内部留出。** 从原训练划分中冻结开发 100 张和独立内部留出 120 张，按数据源和目标面积分层，覆盖小目标及空场景。优先使用未参与历史训练、模型选择及诊断的图像。FS0 先验证容量和覆盖，若不足，登记缺口并在冻结前调整。开发集用于选择 checkpoint，内部留出只用于冻结后的确认。
- **官方测试。** 保留 EORSSD 600、ORSI-4199 2,199、ORSSD 200 的原官方清单。FS0 先按样本 ID 与图像 SHA-256 排除跨训练、开发、内部留出及官方测试的重复，精确重复成组隔离。对近重复候选人工核实并记录处置。历史审计发现训练池与官方测试有 2 条精确重合，官方测试跨源有 42 组精确重复；本路线重新生成审计报告，主表保留官方清单，另报按内容去重的敏感性结果。
- **完整 GT。** 只有 FS 训练进程可从对应训练允许清单读取完整掩码。开发、内部留出和官方测试的 GT 由各自的独立评分进程读取。Qwen 缓存与各组预测只读图像。审计记录样本角色、图像与掩码哈希、访问阶段和配置哈希。GT 几何变换与输入同步，掩码用最近邻插值，补边置为 ignore。

## 3. 实验组、训练预算与评价门槛

| 实验组 | 输入与训练方式 | 用途 |
|---|---|---|
| FS-RGB | 原图，经冻结 DINOv2 编码；额外通道全零，预测头用完整 GT 训练 | 同架构全监督对照，可独立部署 |
| FS-Qwen | 相同原图、编码器和预测头；额外通道输入冻结 Qwen 的显著亮度图，预测头用相同完整 GT 训练 | 检验 Qwen 先验增益 |

两组固定 350 输入、初始化、样本顺序、几何增强、BCE + soft Dice、优化器、评估频率和 checkpoint 选择规则。GT 原分辨率用于评分，恢复预测时沿用冻结指标实现的几何映射。初始预算沿用 B500 参照的 AdamW（学习率 3e-4，权重衰减 1e-4）、batch 4、累积 2、250 步 warmup 后余弦衰减、最多 5,000 步、每 250 步评估；最早在 2,000 步后允许按 patience 6、最小增益 0.002 早停。按开发集最高 Sα 选 checkpoint，同分优先低 MAE，再优先较早步。FS0 冻结预算及种子 20261105、20261106、20261107；FS3 先跑首种子，FS4 补齐其余种子。扩量时用每组相同的预冻结样本曝光预算，单列训练规模、更新步数与 GPU 小时。

首轮使用已验证的 P2@1024、40 步 Qwen 输出，按固定种子生成 RGBA 并转 BT.601 亮度。复用前匹配模型、提示词、调度器、步数、种子、输入内容和转换代码；缺项按新清单生成。训练增强同时作用于原图、亮度图与掩码。首轮将速度独立报告；若后续目标包括 15 秒端到端部署，再以单独原子步验证加速。

**建议立项门槛，在 FS0 冻结。** 首种子开发集筛选要求 FS-Qwen 相对 FS-RGB 的 Sα ≥ +0.005、MAE 增量 ≤ 0.002、Boundary-F 降幅 ≤ 0.010。多种子确认在冻结内部留出集上沿用同样阈值，并要求 Sα 配对差的 95% 区间下限 > 0。每张图先对三个配对种子的分差取均值，再按数据集分层、按图像内容分组做配对 bootstrap，同时报告各 seed 和数据集的差值。未达到门槛时保留完整结果，以 FS-RGB 作为全监督路线后续扩量候选。

统一报告 Sα、MAE、Fmax、Boundary-F、IoU，按数据集、目标面积及空场景分层。端到端计时包含 Qwen 生成及预测头推理，另列只读缓存的推理时间、冷启动与稳态均值/P95、显存峰值和 GPU 小时。以三个数据集分列结果为主，合并逐图均值作为补充。

## 4. 单步执行与验收

| 步骤 | 执行内容 | 验收依据 |
|---|---|---|
| FS0 协议与数据冻结 | CPU 审计清单、GT 登记、跨角色重复和旧缓存。确定分层划分、训练预算、指标、门槛和每档缓存生成量。 | 训练、开发、内部留出、官方测试各角色清单与哈希；训练 GT 精确允许清单；重复审计和缓存命中表。 |
| FS1 CPU 执行链路预检 | 复用 B500 全监督数据、损失与恢复实现，接入额外亮度通道、配对训练及独立评估。 | 样本顺序确定、增强对齐、ignore 像素梯度为零、空掩码损失有限、越权读取和错误哈希被拒绝、checkpoint 重载后续步一致。 |
| FS2_MIN 最小缓存及单卡冒烟 | 冻结小样本清单，验证实际 Qwen 缓存、两组短训练及峰值显存。 | 缓存逐像素可复算，两组权重正常更新且可恢复，训练只读允许清单，显存不超过 22 GB。 |
| FS2_CACHE B500 缓存 | 复用符合冻结协议的缓存，补齐 B500 及开发集需要的条目。 | 图像、亮度图及完成记录一一对应，逐图哈希一致，生成阶段 GT 读取为零。按 FS0 确定的分片与断点续跑。 |
| FS3 首种子配对筛选 | 两组在相同 B500 上各训一次，用同一开发集选 checkpoint。 | 两组训练及评分退出码、产物哈希和审计齐全，单独记录技术验收和开发集筛选结论。 |
| FS4 多种子确认 | 筛选通过后补两对 seed。预先冻结全部 checkpoint 后，再在同一内部留出集完成评分。 | 配对分差、95% 区间、分层指标与耗时完整，按冻结门槛给出判定。 |
| FS5 扩量训练 | 根据 FS4 结果选定候选，先比较 B1000，再决定是否运行全合格池。每一档独立冻结和验收。 | 记录实际 GT 预算、清单嵌套关系、开发集增益与训练成本；对入选候选完成同预算对照。 |
| FS6 官方测试 | 冻结最终模型、配对对照、种子、清单、后处理和指标代码。预测和评分分别执行。 | 2,999 条配对记录及哈希齐全，三个数据集分列、合并和去重敏感性结果可复算；披露此方案在既有官方测试成绩可见后制定。 |
| FS7 汇总与交接 | 整理模型质量、人工像素 GT 预算、Qwen 贡献、计算成本和全部门槛判定。 | 汇总表可追溯至配置、清单、日志及报告，单列历史 W5 参照。 |

缓存排期先按缺失条目数 × 同配置实测秒/图估算，再加上校验与重试预算。若 600 张全部缺失，按 R8 的 40 步均值 73.81 秒/图估算约 **12.3 GPU 小时**；FS0 以实际缺口替换该估算。内部留出及官方测试所需缓存按各自阶段另行冻结。

## 5. 远端隔离、状态与恢复

- 在远端使用独立的 `configs/full_supervision/`、`manifests/full_supervision/`、`runs/full_supervision/` 和 `reports/FS_*`，所有写入位于 `/data2/wangsiyi`。历史 W5、R 系列资产以只读方式引用。
- 执行前读共享进度说明与远端状态，检查对应完成标记、产物及断点。监控按项目规则从 ready 到 running，单 RTX 3090 经既有 wrapper 和独占锁运行，显存上限 22 GB。占用时按 paused 记录。长任务用命名 tmux，日志记录退出码、运行 ID、配置和种子。
- 缓存以逐图完成记录恢复；训练检查点包含优化器、采样位置、随机状态及配置哈希。失败保留原日志，重新预检后从已验收断点恢复。各原子步骤完成后核对远端状态、`reports/NEXT_ACTION.md`、监控和共享进度说明；验收通过后以原子替换方式登记对应完成标记。
- 本版仅完成路线设计。首个可执行原子步骤是 **FS0 协议与数据冻结（CPU）**。

## 6. 标准指标复核与竞争性实验

2026-11-11 对 B500 已保存的 2,999 张 PNG 做只读 CPU 复算。旧脚本的目标项和区域项与标准 S-measure 有差异，区域按图像中心切分。PySODMetrics 按 GT 前景质心切分并按区域面积加权。复算采用固定提交 `2be5e5567825533f25358f87788337f9c306513b` 的 Smeasure，保留默认逐图归一化结果，并用 PNG/255 另算一遍。后者合并 Sα 为 0.830844，说明差异主要来自公式。旧验收及冻结门槛按各自历史口径保留。

| 数据集 | 旧 Sα | 标准 Sα | MCCNet 公开 Sα | 差距 |
|---|---:|---:|---:|---:|
| EORSSD | 0.722935 | 0.830474 | 0.9327 | 0.102226 |
| ORSSD | 0.819407 | 0.876187 | 0.9437 | 0.067513 |
| ORSI-4199 | 0.751967 | 0.827274 | 0.8746 | 0.047326 |
| 合并 | 0.750656 | 0.831176 | | |

面积不超过 2% 的 862 张非空图，标准 Sα 为 0.786011，既有 0.5 阈值 IoU 为 0.519617。中等面积组的标准 Sα 为 0.850872，IoU 为 0.706120。该分析用于确定小目标分层指标，模型选型和阈值选择在开发集完成。

先按 ORSSD 单数据集做低成本验证。其原训练划分有 600 张，官方测试 200 张，便于跑通专用模型训练和同脚本评测。FS0 冻结标准指标代码、排重后的开发划分、训练预算与验收门槛。优先取得 GeleNet 或 MCCNet 作者发布的预测图，用相同 GT、尺寸恢复、归一化和代码复评分。IPDiff 公布了 MATLAB 评分工具，论文分数目前作为外部参考。

训练先复现一个可训练的多尺度专用基线，优先采用公开 GeleNet/PVT 实现，记录与论文训练配置的差异。基线跑通后，用相同训练图、种子、损失和 checkpoint 规则做一对实验。两组均保留原图分支与同形状的残差融合层，一组将 Qwen 通道置零，另一组输入冻结 Qwen 亮度图；残差分支从零输出起步。小目标子集另报 Sα、IoU 和边界 F。若先验有稳定增益，再把同协议扩展至 ORSI-4199 和 EORSSD；若增益不足，保留专用基线作为性能路线，继续用小目标与边界误差决定下一次单变量改动。

建议在 FS0 把“接近 MCCNet”冻结为同口径 Sα 差 ≤0.010 且 MAE 增量 ≤0.002；“超过”要求相同样本的 Sα 配对差 95% 区间下限 >0 且 MAE 不升。最终成绩按数据集和种子分别报告。以上为后续独立实验方案，本次只有评分复核。
