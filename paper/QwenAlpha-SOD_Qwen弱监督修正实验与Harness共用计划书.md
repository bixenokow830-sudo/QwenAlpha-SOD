# QwenAlpha-SOD 弱监督修正实验与 Harness 共用计划书

版本 v1.0，2026-11-07，Asia/Shanghai。Codex 与 DeepSeek Harness 共用本计划和仓库共用进度说明书。

## 目标

冻结 Qwen-Image-2.1 P2@1024。修正器接收遥感原图和 Qwen 亮度图，输出原图坐标系下的单通道显著图。训练用人工点、涂鸦和经过审核的 SAM 伪标签。人工标签只在训练时提供。推理时仍运行 Qwen，最终评分归于 Qwen 与修正器组成的系统。

在同一开发集比较四组。A 是原始 Qwen，B 是已有 W2.5 固定规则，C 是使用 Qwen 图的弱监督修正器，D 是同结构、同训练样本、同训练预算的修正器，将 Qwen 输入通道置零。C 对 B 检验新方法的实用增益，C 对 D 检验 Qwen 输出是否带来额外价值。W5 的 0.7233 和此前 Q3 训练图分数单独记录。

## 数据与训练约束

- 从 B500 中选 32 张已有真实弱标注且伪目标通过 Q1 检查的训练图，覆盖三数据集，包含小目标和空场景。排除 Q1 确认与测试图重复的样本及停车场待复核样本。候选须逐图复核前景、背景、点和涂鸦一致性，按冻结规则选样。冻结后记录原图、弱标签、掩码及其 SHA-256。
- 首轮使用 W1/W2.5 已有缓存的完整 100 张开发图做一次冻结配置筛选报告。W2.5 曾在这 100 张图上选参，报告注明它是历史开发集。只有单独冻结并核验的未参与调参的评估集才能提供独立确认。官方测试不用于选样或选参。
- 使用相同的原图编码器、轻量预测头和输入结构训练 C/D。优先复用冻结 DINOv2 特征与 W5 数据隔离逻辑。C 输入实测 Qwen 亮度图，D 对应通道恒为零，两组均直接预测显著概率。人工点涂鸦的损失优先，合格 SAM 的确定区提供辅助密集损失，未确定像素从伪标签损失中排除。确定空场景提供背景监督。
- 预先冻结训练步数、种子、采样序列、权重和推理几何。两组固定末步检查点作为首轮比较，复核不合格样本时保留记录。使用统一的 BT.601 与同版本评测器，生成和训练仅接触训练允许清单，GT 由独立评测器按角色读取。
- 开发筛选门槛在训练前冻结。建议 C 对 B 和 D 的平均 Sα 均至少增加 0.01，且相对 B 的 MAE 退化不超过 0.002、Boundary-F 下降不超过 0.01。报告配对样本差、固定种子配对 bootstrap 区间和各数据集、小目标、空场景结果。筛选通过后单列独立确认，样本量有限时保留不确定性。

## 原子步骤

| 步骤 | 工作 | 验收和交接证据 |
|---|---|---|
| R0 计划与数据预检 | 写好共用计划。核对弱标注训练候选、开发缓存、评测器与训练输入缓存缺口 | 四组及统计口径明确。记录可复用文件数、训练缺口、预检哈希和下一步 |
| R1 冻结 32 张训练清单 | 按已知划分排重，复核伪目标，冻结选样、训练预算和通过门槛 | 三数据集覆盖、无训练完整 GT、训练与开发/测试图像哈希隔离 |
| R2 缓存 Qwen 训练输入 | 逐图生成 P2@1024 原始图及亮度图，沿用 40 步并预先冻结种子。可验证等价的缓存按哈希复用 | 每图持久化，支持按完成记录续跑，32/32 输出及哈希一致 |
| R3 修正器冒烟 | 训练代码和 C/D 两个同条件短试验，核对输入置零、未知区域屏蔽及恢复 | 无 GT 访问，参数更新、输出尺寸、检查点重载、显存均通过 |
| R4 配对训练 | 用相同样本、步数和随机顺序训练 C、D | 两组检查点、配置、日志与访问审计齐全 |
| R5 开发集盲跑预测与评分 | 生成 C/D，再用独立评测器统一计算 A/B/C/D | 完整配对表、分层结果和预设门槛判定。未过门槛保留结果并停在此处 |
| R6 独立确认 | R5 通过后另冻结未参与调参的评估集、最终配置和对照 | 统一口径确认增益与 Qwen 贡献，披露历史开发选择与实际推理时间 |
