# QwenAlpha-SOD：Qwen 本体 LoRA 显著图适配分步与双 Agent 交接计划

**版本：** v1.0　**日期：** 2026-11-07（Asia/Shanghai）　**状态：** 已制定，GPU 训练未开始

## 0. 目标与监督定义

研究目标是保留“遥感原图＋固定提示词→Qwen-Image-2.1 生成→显著图”的推理主干，训练挂载在 **Qwen 生成 Transformer 内部**的 LoRA，使同一模型直接生成更准确的显著图。输出采用黑背景、白主体的 RGB 图，再按冻结亮度公式生成灰度显著图；Alpha 仅作诊断。最终推理必须实际运行 Qwen 和该 LoRA，不能用独立 DINOv2 学生网络的分数或速度冒充 Qwen 结果。

**本计划的主实验属于弱监督**：训练信号来自真实人工点／涂鸦以及它们提示 SAM 得到并经过资格审查的伪掩码，不读取训练图完整像素 GT。伪掩码是密集的、带噪声的代理标签，因此应准确写成“点／涂鸦弱监督＋伪标签 LoRA 微调”，不能称无监督或零训练。100 张开发集 GT 仅供选模型和评测。若以后使用完整训练 GT 制作目标图或训练损失，该分支立即改称**全监督**，单列实验和结果，不混入本主实验。

## 2. 执行边界与状态事务

1. 本计划与仓库根目录 `AGENTS.md`、`paper/QwenAlpha-SOD_Harness与Codex共用进度说明书.md`、`paper/QwenAlpha-SOD_Codex额度不足时Harness续执行计划书.md` 一起阅读。用户最新指令优先；每次只执行用户请求的**一个原子步骤**，验收和更新状态后停止。
2. 远端所有写入仅在 `/data2/wangsiyi`；不碰其他用户进程或目录。GPU 只用一张 RTX 3090，调用现有 `scripts/run_single_gpu.sh` 的锁和独占检查，峰值 ≤22 GB。不可用时记 `paused`，不排队轮询。
3. 每步执行前把远端 `monitor/status.json` 设为 `ready` 并给用户 `http://127.0.0.1:8765/`；开始设 `running`。长任务用命名 tmux、退出码和分片／检查点，按事件验收，不做高频轮询。
4. 每次状态变化在同一步原子更新 `state/active_run.json`、`state/progress.yaml`、`reports/NEXT_ACTION.md`、HTML 监控和共用进度说明书。只在验收全部通过后写 `state/done/Q*.done.json`。失败保留日志、配置、种子和安全检查点。
5. 用户可在任意节点把后续**单步**交给 DeepSeek Harness 或 Codex。接手 agent 先比对实际产物、done marker、配置 hash、状态与日志；有冲突先记录并修正，不重跑已有效步骤。公共文档更新成功后按 `AGENTS.md` 只执行一次白名单 GitHub 同步。

## 3. 冻结的科学比较口径

- 输入：同一原图、同一 P2 提示词、同一采样步数、种子、输出尺寸；只改变 Qwen 内部 LoRA。若 512px 训练可行但 1024px 推理不可行，512px 原模型对照必须**另跑同样样本**，不可与旧 1024px 分数直接相减。
- 主输出：RGB BT.601 亮度灰度图；不得在开发或测试评分后逐图选亮度／Alpha、阈值、种子或提示词。记录 Sα、MAE、Fmax、Boundary-F、按数据集和小目标分组结果、显存及秒／图。
- 训练池与开发集独立；官方测试只在开发方案冻结后使用。由于官方分数已知，必须在论文标明测试后设计。若要作真正独立验证，应另留未参与设计的新测试集。
- 严格区分三个对照：原始 Qwen；Qwen＋LoRA；不使用 Qwen 的 W5 学生网络。学生网络只是旁支，不用其 0.034 秒／图作为 Qwen 方法速度。
- 不以 FS 0.750656 或学生 0.723305 作为 LoRA 的目标阈值；小试先看**同图原始 Qwen 的配对增益**和失真，再决定是否扩展。

Q3 的 P2/P3 两轮均未达到原门槛，Q4 保持暂停。路线复核已通过，唯一下一步为 `Q3_LOSS_SMOKE`。使用 ORSI-4199/train/490 的冻结弱目标，512px、P3、rank4、固定种子与 sigma 0.25。将模型预测的干净潜变量解码为 RGB，比较纯流匹配和加入 0.1 倍区域均衡亮度损失的梯度。辅助损失对确定前景和确定背景各取平均并等权合并，排除 Q1 不确定像素。检查 LoRA 辅助梯度有限且非零、基础权重冻结、峰值显存≤22528 MiB、无 GT 访问，至多一次参数更新。该测试只回答训练可行性，详细冻结范围见远端 `reports/Q3_route_review_acceptance.json`。
