## 0. 执行摘要

当前 Qwen-Image-2.1 的 P2@1024 零训练探针在 10 张开发样本上取得 `Sα=0.5900 / MAE=0.0322`。该结果证明模型具有显著主体语义，但距离传统全监督遥感 SOD 约 0.90 的参照水平仍有明显差距。S2.3 同时证明 Qwen 原生 RGBA VAE 对软边和小目标存在表示损失，因此后续不把 Qwen 生成的 Alpha 或亮度图直接当作最终预测头。

本计划采用以下职责分离：

1. **Qwen**：产生“哪个区域可能是显著主体”的语义先验。
2. **SAM**：把粗语义区域转换成边界清晰的候选对象掩码。
3. **DINOv2**：提供无需人工标注的区域语义一致性与增强稳定性证据。
4. **点/涂鸦弱标注**：消除“哪个对象才显著”的歧义，控制伪标签错误传播。
5. **轻量学生网络**：直接输出单通道显著图，绕开 Qwen VAE 的最终表示瓶颈。

主路线不是传统全监督：禁止使用训练集完整像素 GT 更新模型。最终评分仍使用 GT，但官方测试 GT 只能在配置冻结后用于一次性评测。

推荐监督级别是“点标注为主、少量涂鸦补充”的弱监督。严格零标注路线保留为消融，不作为最有希望逼近全监督结果的主路线。

## 1. 科学问题与目标

### 1.1 核心问题

在不使用大规模像素级显著图进行训练的条件下，能否把 Qwen-Image-2.1 的开放语义能力、通用分割基础模型的边界能力和自监督视觉特征结合起来，使遥感显著性检测性能接近传统全监督方法？

### 1.2 主要目标

- 建立可复现的 P2@1024 零训练基线。
- 生成有置信度和 ignore 区域的多教师伪标签，而不是把单一教师输出硬阈值化。
- 以极低标注预算确定前景/背景语义，不使用完整训练掩码优化模型。
- 训练一个直接预测灰度显著图的学生网络。
- 在 EORSSD、ORSSD、ORSI-4199 上报告与全监督参照线的绝对差距和差距闭合率。
- 通过消融证明 Qwen、SAM、DINOv2、弱标注、边界损失和自训练各自的贡献。

### 1.3 不承诺的事项

- 不预先承诺必然达到 `Sα=0.90`。
- 不因结果不理想而修改测试集、删除难例或事后改变指标。
- 不把使用过 GT 的提示词/阈值选择描述为严格无监督。
- 不把外部全监督 SOD 模型生成的伪标签包装成无监督方法。

## 2. 监督口径与 GT 防火墙

### 2.1 四种口径

| 口径 | 训练阶段允许使用 | 本项目用途 |
|---|---|---|
| Z0 严格零标注 | 原图、冻结基础模型、自监督一致性 | 必做消融 |
| W1 点监督 | 每个显著对象的正点和少量背景点 | 推荐主监督 |
| W2 涂鸦监督 | 稀疏前景/背景笔画 | 难例增强 |
| FS 全监督 | 完整像素 GT | 仅作外部/内部上限参照，不进入主方法训练 |

### 2.2 数据角色冻结

1. **10 张 S2.4 探针**：已用于选择 P2 与 1024，只能视为带 GT 的协议校准样本。
2. **100 张 `vae_audit`**：开发/诊断集，用于冻结伪标签阈值、损失权重和停止规则，不得作为论文最终测试结果。
3. **官方训练划分**：主训练池。训练程序只能访问原图、弱标注和伪标签；完整 GT 必须通过路径和代码防火墙隔离。
4. **内部弱监督验证集**：从训练划分固定抽取，允许使用 GT 做模型选择，但必须单独披露数量。
5. **官方测试划分**：配置冻结后只运行一次；不得用于提示词、阈值、checkpoint 或损失选择。

### 2.3 弱标注来源

优先使用人工点/涂鸦，因为它最能支持真实的低标注成本主张。若为了基准复现从完整 GT 自动采样点或骨架涂鸦，必须标记为“模拟弱标注”，并单独报告；不得宣称这些标注真实只花费了点/涂鸦的人工成本。

每次发布结果必须同时报告：

- 有弱标注的图像数；
- 正点、背景点、涂鸦笔画数量；
- 每图平均点击数和估算/实测标注时间；
- 使用完整 GT 的开发图像数；
- 官方测试 GT 是否参与过任何模型选择。

## 3. 方法总览

```text
原始遥感图像
   ├─ Qwen P2@1024 ───────→ 粗显著语义先验 q(x)
   ├─ DINOv2 ─────────────→ 像素/patch 自监督特征 f(x)
   ├─ SAM 自动/点提示 ────→ 候选掩码 {m_k}
   └─ 稀疏点/涂鸦 ───────→ 显著对象约束 a(x)
                              ↓
                   候选评分、共识融合、不确定性估计
                              ↓
                 前景 / 背景 / ignore 三值伪标签
                              ↓
             冻结编码器 + 轻量多尺度显著性学生网络
                              ↓
                    单通道灰度显著图（最终输出）
```

设计依据：SAM 提供可提示的零样本分割和自动候选掩码能力；DINOv2 提供不依赖目标任务标注的通用像素特征；SAMRS 表明遥感域分割预训练/适配有价值；点监督和涂鸦监督 SOD 已证明稀疏标注、伪标签扩张和边界约束可以显著缩小与全监督方法的差距。

## 4. 教师信号与伪标签生成

### 4.1 Qwen 语义先验

沿用已经冻结的 S2.4 协议：

- 提示词 P2：`Remove the background and keep only the salient object, on a pure black background.`
- 1024 面积预算，保持长宽比并对齐 32。
- 40 步，固定 seed 规则，bf16，单 GPU CPU offload。
- 用 BT.601 亮度产生连续先验 `q(x)`。

零训练基线不做拉伸、gamma 或后处理。用于训练伪标签的版本可以生成置信度，但所有变换必须在开发集冻结，并作为“方法模块”单独做消融。

### 4.2 SAM 候选掩码

每张图生成两组候选：

1. 自动掩码候选：覆盖未知数量和尺度的对象。
2. 弱提示候选：由正点、背景点或涂鸦包围框提示。

保留 SAM 的 predicted IoU、稳定性分数、面积、边界和嵌套关系。不得简单选面积最大的掩码，因为遥感显著目标经常很小或多实例。

### 4.3 DINOv2 一致性

从冻结 DINOv2 提取 patch 特征，评估：

- 掩码内部特征紧致度；
- 掩码与外部背景的特征分离度；
- 原图、水平翻转、轻度颜色扰动、两种尺度下的特征/掩码一致性；
- 多实例是否具有相似显著语义。

DINOv2 不直接决定“显著”，只判断候选区域是否语义一致和跨增强稳定。

### 4.4 候选评分

对候选掩码 `m_k` 定义冻结评分：

```text
C(m_k) =
    wq · QwenOverlap
  + wd · DinoCoherence
  + wa · AugmentationStability
  + ws · SamQuality
  + wp · WeakPromptAgreement
  - wb · BorderLeakPenalty
  - wf · FragmentPenalty
```

其中 `WeakPromptAgreement` 在零标注消融中置零。所有权重和阈值只在100张开发集冻结，不得参考官方测试集。

### 4.5 三值标签

不要生成“每个像素非黑即白”的伪 GT，而应输出：

- `foreground`：至少两类教师一致，且满足弱标注约束；
- `background`：所有教师均低置信，且不与正点/前景涂鸦冲突；
- `ignore`：教师冲突、边界带、嵌套歧义、低置信小目标。

训练初期只使用高置信区域；随 EMA teacher 稳定后再逐步扩大监督区域。

## 5. 弱标注方案

### 5.1 推荐最小预算

每张已标注训练图：

- 每个显著对象至少 1 个正点；
- 2 个明确背景点；
- 对 small/thin/multi/low_contrast 等难例补 1 条短前景涂鸦；
- 如背景容易混淆，再补 1 条背景涂鸦。

### 5.2 预算递增实验

| 级别 | 图像数 | 标注形式 | 用途 |
|---|---:|---|---|
| A | 100 | 点 | 流程和损失单元验证 |
| B | 500 | 点；难例加涂鸦 | 第一版主结果 |
| C | 1,000 | 点；难例加涂鸦 | 标注规模曲线 |
| D | 全部训练图 | 点；约20%难例涂鸦 | 最终弱监督上限 |

必须分层覆盖数据集、目标面积、多目标、细长、孔洞、低对比、阴影和空场景。预算升级必须串行进行；B 未显示稳定增益时不得直接扩大到 D。

### 5.3 标注质量检查

- 正点必须落在目标内部，背景点不得落在目标上；
- 涂鸦不得跨越明显边界；
- 空场景只允许背景标注；
- 5% 样本双人复核或重复标注，报告一致率；
- 所有弱标注保存原始坐标、时间、标注者/生成方式和哈希。

## 6. 学生网络

### 6.1 推荐结构

首选轻量、可解释且适合单卡的结构：

- 冻结 DINOv2 ViT-S/B 或遥感适配编码器；
- 提取 4 个层级的 token 特征；
- 轻量 FPN/MLP decoder 恢复多尺度空间信息；
- 独立边界头；
- 最终 sigmoid 输出单通道显著概率图；
- 不经过 Qwen VAE。

SAM 图像编码器可作为第二编码器消融，但主模型不同时训练 Qwen、SAM 和 DINOv2 的大编码器。默认冻结教师，只训练 decoder；必要时仅对最后若干层使用 LoRA/adapter。

### 6.2 训练分辨率

- 初始冒烟：320/352。
- 正式训练：多尺度 `{320, 352, 384}`，保持长宽比并 padding。
- 最终推理：原图或冻结的长边/面积预算，输出再恢复到 GT 原尺寸。
- mask resize 使用双线性预测、最近邻离散标签；ignore 区域单独维护。

### 6.3 损失

```text
L =
    λp · L_point_or_scribble
  + λm · L_confident_pseudo
  + λb · L_boundary
  + λc · L_multiview_consistency
  + λe · L_ema_distillation
  + λs · L_small_object
```

- `L_point_or_scribble`：只在人工弱标注像素上计算 BCE/focal。
- `L_confident_pseudo`：高置信区域的 BCE + soft Dice/IoU。
- `L_boundary`：基于 SAM 边界或距离变换，ignore 不参与。
- `L_multiview_consistency`：几何增强反变换后保持预测一致。
- `L_ema_distillation`：EMA teacher 仅在置信度超过冻结门槛时监督。
- `L_small_object`：按目标面积和难例标签提高小目标区域权重，但不得引用测试 GT。

所有 λ 在开发集冻结。每次消融只改变一个变量。

### W1：冻结100张零训练基线

任务：按 S2.4 协议在100张 `vae_audit` 上完成 P2@1024，仅运行一次。

输出：

- `reports/W1_qwen_zero_shot_100.json`

### W2：多教师伪标签原型

依次运行，不并行占卡：

1. Qwen-only 连续先验；
2. SAM-only 自动候选；
3. Qwen + SAM；
4. Qwen + SAM + DINOv2；
5. 加弱点约束。

先在100张开发集评估伪标签质量和覆盖率，再决定是否批量生成训练池伪标签。

Go 条件：相比 Qwen-only，融合后 Sα 至少提高 0.10，且 MAE、Boundary-F 不恶化；小目标子集不得系统性下降。

No-go：若 SAM 遥感域候选覆盖严重不足，先评估遥感适配 SAM/SAMRS 初始化，而不是降低质量阈值制造噪声。

### W3：弱标注100张与标注工具验收

- 标注 A 级100张；
- 记录实际时间和点击数；
- 对 SAM 候选进行点/涂鸦提示；
- 输出三值伪标签和可视化审计拼图；
- 人工复核最差20张。

Go 条件：正点覆盖率100%，背景冲突为0；高置信伪标签覆盖足够训练，且比无弱标注融合稳定。

### W4：64张过拟合与损失验证

- 使用既有48+16 overfit 子集，但训练端只读取弱标注/伪标签；
- 完成1、10、100、500 step；
- 验证 checkpoint、暂停恢复、梯度和 ignore mask；
- 比较正确图像、打乱图像和纯黑图像。

Go 条件：训练弱标注满足率 ≥99%，验证 Sα 明显超过 W1 教师，反事实输入导致性能显著下降，峰值显存 ≤22 GB。

### W5：500张主路线训练

- 扩展到 B 级500张弱标注；
- 其余无标注训练图使用高置信伪标签；
- 冻结主结构、优化器、学习率、loss λ 和伪标签阈值；
- 训练最多3个种子，严格串行。

阶段门槛：

- `Sα < 0.75`：停止并诊断伪标签语义错误；
- `0.75 ≤ Sα < 0.82`：只允许修正伪标签/小目标模块，不扩大标注预算；
- `Sα ≥ 0.82`：允许进入 W6；
- 单一模块提升小于0.005：标记 rejected，不叠加。

### W6：1,000张与全训练池弱监督

按 B→C→D 的预算顺序扩展。每次扩展必须保留相同开发集和指标代码。

目标不是只看绝对 Sα，还要计算差距闭合率：

```text
GapClosure = (S_weak - S_zero) / (S_full_reference - S_zero)
```

目标：在至少两个数据集上闭合 ≥80% 的零样本到全监督差距；同时 MAE、Fmax、Emax 和 Boundary-F 不出现明显反向退化。

### W7：两轮以内自训练

1. 用 W6 最佳 checkpoint 生成全训练池 soft prediction；
2. 与原 Qwen/SAM/DINO 共识重新评分；
3. 仅替换置信度更高的伪标签区域；
4. 训练 EMA student；
5. 最多两轮。

停止规则：一轮开发集 Sα 增益 <0.005，或小目标/跨数据集性能下降，则停止；禁止不断自训练直到开发集偶然升高。

### W8：冻结、官方测试与统计

- 锁定代码、配置、checkpoint、弱标注 manifest 和伪标签 manifest 的 SHA-256；
- 冻结后在官方测试集一次性推理；
- 分别报告 EORSSD、ORSSD、ORSI-4199；
- 三个种子报告均值±标准差；
- 报告全体、small/thin/multi/low_contrast 等难例；
- 与传统全监督方法在同数据划分、同指标实现下比较。

最终主张按结果分级：

- 与全监督差距 ≤0.02：可称“接近全监督水平”；
- 差距 0.02–0.05：称“显著缩小差距”；
- 差距 >0.05：不得使用“接近”措辞。

## 8. 单卡资源计划

- 所有 GPU 步骤必须通过 `scripts/run_single_gpu.sh <physical_gpu> -- ...`。
- 每次启动前重新查询 GPU，不沿用文档中的旧空闲卡结论。
- 单进程只看到 `cuda:0`，禁止 `device_map=auto`、DDP、多卡或终止他人任务。
- 峰值显存硬上限22 GB。
- Qwen、SAM、DINOv2 教师信号离线分阶段缓存，不同时常驻 GPU。
- 教师缓存按 shard 原子写入；训练读取缓存，减少重复大模型推理。
- batch 从1开始，使用 bf16、gradient accumulation、activation checkpointing；先测峰值再扩大。

## 9. 状态、暂停与恢复

每个 W 步骤遵循仓库根 `AGENTS.md` 的原子协议：

1. 监控置 `ready` 并向用户展示 URL；
2. 写 active run 和 history；
3. 命名 `tmux` 启动；
4. 分片完成后校验数量、哈希、shape、finite；
5. 通过才创建 `state/done/Wx.done.json`；
6. 更新 `progress.yaml`、`reports/NEXT_ACTION.md`、共用进度说明书；
7. 停止，不自动进入下一 W 步骤。

恢复时只补 pending/failed shard，不覆盖 hash 正确的已完成缓存。配置 hash、数据 manifest、弱标注 manifest 或教师版本变化时必须新建 run，禁止混用旧 checkpoint。

## 10. 风险与止损

| 风险 | 表现 | 处置 |
|---|---|---|
| Qwen 语义错误 | 选到背景/大建筑纹理 | 弱点约束、教师共识、低置信 ignore |
| SAM 遥感域偏差 | 小目标漏检、候选碎片化 | 多尺度/切片、遥感适配初始化、边界合并 |
| 伪标签确认偏差 | 自训练越来越自信但错误 | EMA、置信度分级、最多两轮、开发集停止规则 |
| 小目标消失 | 总体指标尚可但 small 崩溃 | 小目标过采样、尺度训练、独立门槛 |
| GT 泄漏 | 结果虚高、监督口径不成立 | 路径防火墙、文件打开审计、测试只跑一次 |
| 标注预算失控 | 实际接近全监督成本 | 记录点击/笔画/时间并画预算曲线 |
| 单卡 OOM | 教师同时常驻 | 离线缓存、逐模型运行、decoder-only 训练 |
| 百度同步盘干扰 Git | lock/临时文件冲突 | 大产物只放远端，Git 由本机显式操作 |

## 12. 开工前决策点

在执行 W0 前，用户需要确认主路线监督预算：

1. **推荐：点监督 + 约20%难例涂鸦**。成功概率最高，仍明显低于完整像素标注成本。
2. **纯点监督**。标注最简单，但边界主要依赖 SAM，遥感域风险更高。
3. **严格零标注**。只使用 Qwen、SAM、DINOv2 共识；适合作为消融，不建议作为唯一主路线。

无论选择哪一项，当前下一原子步骤仍是完成已经冻结的100张 P2@1024 零训练开发基线。完成后才进入 W0，且每次只执行用户明确指定的一个步骤。

## 13. 方法依据

- [Segment Anything, ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Kirillov_Segment_Anything_ICCV_2023_paper.html)：可提示分割与自动掩码候选。
- [DINOv2: Learning Robust Visual Features without Supervision](https://arxiv.org/abs/2304.07193)：无需目标任务标注的通用视觉特征。
- [SAMRS: Scaling-up Remote Sensing Segmentation Dataset with SAM](https://arxiv.org/abs/2305.02034)：SAM 与遥感分割数据/域适配。
- [Weakly-Supervised SOD Using Point Supervision](https://arxiv.org/abs/2203.11652)：点监督、伪标签扩张和非显著抑制。
- [Weakly-Supervised SOD via Scribble Annotations, CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Zhang_Weakly-Supervised_Salient_Object_Detection_via_Scribble_Annotations_CVPR_2020_paper.html)：涂鸦监督、边缘任务和迭代标注增强。
- [Scribble-based Boundary-aware Network for Remote Sensing SOD](https://arxiv.org/abs/2202.03501)：遥感域涂鸦监督与伪边界学习。

这些工作只提供设计依据；本项目的结论必须由冻结数据划分、统一指标和实际实验支持。
